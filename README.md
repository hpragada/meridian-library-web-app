# Meridian Library

A community library web application for Meridian Library, Fenner Road.

Browse the catalogue, check what is on loan, see what is on this month, and manage your
membership.

## Running it

```
npm install
npm start
```

The site is then at http://localhost:4180.

## Stack

Node.js and Express, with EJS templates rendered on the server. No client-side framework and no
build step — what is in `views/` is what the browser receives.

## Accessibility

Meridian Library conforms to WCAG 2.1 Level AA. Last audited March 2024.
